# TorrentFlow Android Companion

This directory is reserved for the native Android companion application.

The implementation blueprint is in [../docs/ANDROID_COMPANION.md](../docs/ANDROID_COMPANION.md).

The first release is deliberately catalogue-only: transfers may be initiated only from signed, allowlisted records for public-domain, openly licensed, or otherwise authorized content. There is no arbitrary magnet, torrent-file, or torrent-URL input in the initial product scope.

No APK is available yet. This placeholder is not a functioning Android application.
